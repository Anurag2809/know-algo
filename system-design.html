9 Engineering Roles

Every Pattern, Every Perspective

The same system looks fundamentally different depending on who's building it. Each cluster page breaks down exactly what each role owns and optimizes for.

🖥️
Infrastructure Engineer
Servers, cloud resources, auto-scaling groups, cost optimization, IaC (Terraform/Pulumi), provisioning, capacity planning, and on-call runbooks.
🌐
Network Engineer
Latency, bandwidth, DNS design, BGP routing, CDN edge placement, load balancer config, anycast, DDoS absorption, and TCP tuning.
🏗️
Platform Engineer
Developer experience, service mesh, Kubernetes patterns, CI/CD pipelines, internal tooling, service catalog, and golden paths.
🔒
Security / Cyber Engineer
Threat modeling, encryption, AuthN/AuthZ, zero trust rollout, secrets management, compliance (SOC 2, GDPR, HIPAA, PCI-DSS).
📊
Data Engineer
Storage selection, pipeline design, consistency model, schema evolution, partitioning strategy, data lineage, and backfill.
🤖
ML / AI Engineer
Feature stores, model serving latency, training pipeline design, drift detection, vector databases, and embedding serving infrastructure.
⚙️
Backend Engineer
API design, database query optimization, caching strategy, service boundaries, connection pooling, and framework-level decisions.
🎨
Frontend Engineer
CDN for assets, SSR vs CSR vs SSG tradeoffs, API contracts, optimistic UI updates, offline-first design, and bundle strategy.
📈
SRE / Reliability Engineer
SLOs, error budgets, incident response design, on-call philosophy, chaos engineering, runbooks, and postmortem culture.
